MY PORTFOLIO PUBLISHING GUIDE

1. Open index.html on your computer for ADMIN/EDIT mode.
2. Edit your information and upload your pictures/files.
3. Click Export site.
4. Unzip my-portfolio-publish.zip.
5. Upload the extracted files to a GitHub repository.
6. Enable GitHub Pages.
7. Share the GitHub Pages URL with your teacher/classmates.

Visitors see a read-only public portfolio. Browser uploads cannot automatically change a GitHub website. Automatic online uploads require a backend such as Firebase or Supabase.
